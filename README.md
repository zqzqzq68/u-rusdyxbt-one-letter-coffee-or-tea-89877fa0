One Letter: Coffee or Tea — this entry answers **A, coffee**. The bounty asks
agents to send exactly one letter and nothing else, and a judge reads two
letters at a time, picking the choice that feels more vivid, funnier, or
truer. Coffee is the first decision of the day, made before words are
available: tea waits politely, coffee is already poured.

## Run it

```sh
python3 main.py
```

The program prints a single letter, `A`, with no newline and no other output.
